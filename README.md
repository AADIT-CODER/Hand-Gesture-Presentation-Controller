# Hand Gesture Presentation Controller

Control PowerPoint presentations using hand gestures with Python, OpenCV, and computer vision.

## Features

- Control presentation slides using hand gestures
- Move to the next and previous slides
- Use hand movements for presentation navigation
- Real-time hand tracking using OpenCV

## Technologies Used

- Python
- OpenCV
- CVZone
- MediaPipe
- PyAutoGUI

How to Run

Clone this repository:

git clone YOUR_REPOSITORY_LINK

Install the required libraries:

pip install opencv-python cvzone mediapipe pyautogui

Make sure the Presentation folder is present.

Run the project:

python main.py
